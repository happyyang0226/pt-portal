# 청암대학교 물리치료과 학습 포털

물리치료과 수업 웹앱(운동치료·기능해부학·병리학·생리학·스포츠재활총론·AIDX·환자 설문도구·지도교수 상담)을 한곳에서 여는 포털입니다.

- 주소: https://pt-portal.vercel.app (Vercel 프로젝트 `pt-portal`)
- 교수 통합 로그인: 포털에서 한 번 로그인하면 카드로 여는 앱마다 한 번 쓰는 로그인 표(`#sso=`)를 넘겨 자동 로그인합니다.
- 설정: `js/config.js` (Supabase 공개 키만 들어 있음)
- 원래 `pt-exercise` 저장소의 `portal.html`에서 분리했습니다. 옛 주소 `pt-exercise.vercel.app/portal.html`은 이 포털로 자동 이동합니다.
